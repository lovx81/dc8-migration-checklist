不能把现在的 DC8 当作 CN2 GT。机房名称里保留“ZNET”，不代表线路仍是早期的 CN2 GT；旧文章、旧套餐截图和历史测评也可能描述的是过去的线路状态。

选择时建议区分这几个概念：

- **机房位置**：DC8 指向洛杉矶的一个数据中心位置。

因此，“DC8 是否适合我”没有脱离用途的统一答案。若你需要的是洛杉矶 VPS，且能接受普通线路在不同网络和时段出现波动，DC8 可以纳入候选。若核心要求是线路优化，就应比较明确提供相应线路的套餐，而不是因为旧称或历史测评而默认 DC8 仍具备该属性。

## 常见问题

### DC8 和 DC3 是同一个机房吗？

不是。DC8 和 DC3 是不同的数据中心编号。历史资料可能把两者都与早期 CN2 GT 或 CN2 服务联系起来，但不能据此认为当前 DC8 仍是 CN2 GT，也不能认为购买任何 KVM 套餐就一定能迁入 DC3 或 DC8。

### 下单时没有 DC8，是不是就不能用？

不一定。购买页面与开通后的迁移列表可能不同；但最终以具体套餐的 KiwiVM 面板为准。开通后若迁移菜单没有 DC8，就不要假设该套餐具备迁移资格。

### 哪个套餐最适合 DC8？

没有仅凭机房名称就能确定的“最佳套餐”。先确认套餐能否迁入，再按 CPU、内存、存储和流量选择。若只是轻量开发或个人服务，小规格可能已够用；需要承载更大负载时，再考虑更高配置。

### DC8 的速度能保证吗？

不能用单一测试结果保证所有地区、运营商和时段的表现。公开测评是特定时间和网络环境下的观察，不是对未来性能的承诺。对延迟或丢包敏感的业务，应在购买前评估实际线路，并留出迁移、备份或更换方案的空间。
